# YT Music KeepAlive

A lightweight Chromium extension that prevents music.youtube.com to stop playing for inactivity.

## Installation

- Download from Chrome Web Store
- Download from Edge Add-ons

OR

1. Download latest release
2. Unzip folder
3. Go to extension page in your Chromium browser
3. Enable developer mode
4. Select "Load unpacked" and select the unzipped folder
5. Keep the folder on your pc
